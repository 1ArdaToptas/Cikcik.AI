# Frontend

Resonant ses stüdyosunun React + TypeScript + Vite arayüzü. Kurulum ve çalıştırma adımları için kök dizindeki [README.md](../README.md) dosyasına bakın.

| Klasör | İçerik |
| --- | --- |
| `src/pages` | Panel ve Metinden Sese sayfaları |
| `src/components` | Oynatıcı ve yerleşim bileşenleri |
| `src/context/StudioContext.tsx` | Katalog, geçmiş ve ses üretimi durumu |
| `src/lib/ttsApi.ts` | Backend istemcisi |
| `src/lib/audioStore.ts` | Üretilen seslerin IndexedDB önbelleği |
